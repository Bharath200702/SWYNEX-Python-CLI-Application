# Python Task Manager

## Project Description
A command-line Task Manager built using Python. It allows users to manage tasks through a simple menu.

## Features
- Add new tasks
- View all tasks
- Set task priority: Low, Medium, High
- Delete tasks
- Mark tasks as completed
- Search for tasks
- Save tasks in a text file
- Validate user input and handle errors

## Technologies Used
- Python
- VS Code
- File handling
- Functions and modules
- Exception handling

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `python main.py`

## Project Files
- `main.py` — Main menu and program flow
- `task_utils.py` — Task management functions
- `tasks.txt` — Stores saved tasks
